# Contributing to OCS Study Tools

Use Discussions for questions and ideas, and Issues for specific bugs or source-backed content corrections. You can report an issue without writing code.

For changes, start with an existing issue or discuss the scope with the maintainer. Create a branch, make the smallest useful change, and open a pull request that references the issue. Test the affected page in a browser. If it is a downloadable study tool, test the standalone HTML offline as well. Add a changelog entry for changes that matter to candidates.

For content changes, include the volume, chapter, edition, and printed page where practical. Keep instructor-provided review material separate from the independent Reading Companion. Do not submit restricted materials or actual exam questions.

See [MAINTAINING.md](./MAINTAINING.md) for the release workflow and the [Code of Conduct](./CODE_OF_CONDUCT.md) for participation expectations.
