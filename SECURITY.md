# Security Policy

## Supported version

Security fixes apply to the current GitHub Pages deployment and the latest HTML downloads it provides. Older downloaded copies do not update automatically.

## Reporting a vulnerability

Use the repository’s private reporting option under **Security and quality → Advisories → Report a vulnerability**. Please do not post vulnerability details, credentials, or personal information in public Issues or Discussions.

Include the affected URL or file, browser and version, expected impact, and enough detail for the maintainer to investigate safely. For ordinary usability bugs and historical content corrections, use the public issue templates.
