# Code of Conduct

OCS Study Tools is a community for officer candidates, cadre, and other learners. Everyone should be able to ask a question, report a mistake, or suggest an improvement without being mocked or harassed.

## What we expect

- Welcome people with different levels of experience.
- Critique ideas and study material respectfully. Explain disagreements and cite sources when possible.
- Respect privacy. Keep personal information, restricted or nonpublic materials, and actual exam questions out of public posts.

Harassment, discrimination, threats, personal attacks, and sharing someone’s private information without permission are unacceptable.

## Where this applies

This policy applies to participation in the project’s GitHub Issues, Discussions, pull requests, and other project spaces.

## Reporting and enforcement

Use GitHub’s [reporting options](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) to report abusive users or content. If a report option for repository maintainers is available on the affected item, you can use it for project moderation. Please avoid opening a public issue containing private incident details.

Maintainers may remove inappropriate content, limit participation, or block accounts as warranted. Maintainers should handle reports discreetly and avoid publicly disclosing the reporter’s identity without permission.
